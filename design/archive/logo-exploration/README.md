# Moru UI 로고 탐색 보관본

채택한 ‘선으로 쓴 M’으로 브랜드 페이지를 정리하면서 이전 로고 비교 화면과 다섯 가지 시안을 보관했습니다. 이 폴더는 현재 앱에서 불러오지 않으며 공개 자산 경로에도 포함되지 않습니다.

원래 프로젝트의 경로 구조와 파일 내용을 유지합니다.

- `src/components/LogoExploration.tsx`: 로고 탐색 화면
- `src/components/logo-exploration.css`: 탐색 화면 스타일
- `src/components/brand/logo-concepts.tsx`: 시안 데이터와 SVG 컴포넌트
- `public/brand/concepts/`: 다섯 시안의 심벌·워드마크 SVG 10개

복원할 때는 이 폴더의 `src/`와 `public/` 파일을 프로젝트의 동일 경로로 옮기고 화면 연결을 다시 추가하세요. 현재 사용 중인 공식 로고는 프로젝트의 `src/components/brand/MoruLogo.tsx`, `public/brand/moru-*.svg`, `public/favicon.svg`에서 관리합니다.
