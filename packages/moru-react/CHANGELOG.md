# Changelog

## 0.5.0-beta.3 — 2026-11-16

- Apply Glass and Neon consistently to small form controls, OTP slots, calendar
  selection, navigation, and feedback surfaces.
- Keep code block and table headers from hiding the parent material.
- Preserve effects during hover and press, including secondary buttons, file
  inputs, switches, and selected toggles.
- Preserve semantic colors, error/disabled/loading indicators, keyboard focus,
  nested Default scopes, and accessibility fallbacks.
- Include the current component fixes in JavaScript, declarations, and the shared
  stylesheet. Public import paths and provider props are unchanged.

- Provide separate entry points for charts, tables, carousels, resizable panels,
  and the dashboard, with optional peer dependencies.
