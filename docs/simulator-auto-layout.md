# 시뮬레이터 자동 레이아웃

화면 또는 컨테이너의 **자동 레이아웃**에서 세로 스택, 가로 스택, 그리드를 선택합니다. 간격, 패딩, 정렬을 바꾸면 자식 요소의 위치가 함께 계산됩니다. 자유 배치는 기존처럼 개별 좌표를 사용합니다.

- **가로 스택:** 공간을 나눠 배치합니다. 모바일에서 세로로 쌓기를 켜면 작은 프레임에서는 한 열로 바뀝니다.
- **그리드:** 모바일·태블릿·웹의 열 수를 따로 정합니다. 예제 요약 카드는 1열·2열·3열로 바뀝니다.
- **컨테이너:** 관련 요소를 묶고 내부에 다른 레이아웃을 적용합니다. 콘텐츠에 맞춘 높이를 사용하면 내용이 길어져도 다음 영역과 겹치지 않습니다.
- **요소 너비:** 채우기는 부모의 가용 공간을 사용하고, 고정은 설정한 너비를 유지합니다.

## Moru Pocket 예제

시뮬레이터에서 반응형 모바일 예제를 불러옵니다. 잔액 요약은 그리드, 지출 차트와 최근 거래는 가로 스택으로 구성되어 있습니다. 모바일 프레임에서는 세로로, 태블릿·웹에서는 나란히 배치됩니다. 긴 화면은 프레임 안에서 스크롤합니다.

**흐름 실행** 후 최근 거래 또는 ‘예산과 저축 목표 보기’를 누르면 두 번째 화면으로 이동합니다. 목표 카드를 눌러 알림을 확인하고, 예산 알림 스위치를 바꿔 볼 수 있습니다. 저장 버튼의 알림은 프로토타입 동작이며 실제 계정이나 서버 저장을 사용하지 않습니다.

예제의 텍스트, 카드, 차트, 목록, 버튼, 스위치는 시뮬레이터가 사용하는 Moru 웹 컴포넌트입니다. 컨테이너와 배치 정보는 JSON 내보내기·불러오기와 함께 보관됩니다. 기존 자유 배치 프로젝트도 그대로 열 수 있습니다.

이 화면은 반응형 **웹 프로토타입**입니다. Expo 앱을 생성하거나 실제 iOS·Android 동작을 검증하는 기능은 포함하지 않습니다. 네이티브 구현에서는 같은 토큰과 배치 의도를 `@moru/native` 요소로 옮긴 뒤 터치, 키보드, 안전 영역을 실제 기기에서 확인해야 합니다.
